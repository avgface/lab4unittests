# Общее описание решения
Проект включает в себя четыре файла .py, включающие в себя функции, вычисляющие площадь и периметр для круга (circle.py), прямоугольника (rectangle.py), квадрата (square.py) и треугольника (triangle.py).

# Описание функций
## Функции circle.py
- Area: S = πR²
    - Принимает r - радиус окружности, возвращает ее площадь
        `print(area(4))` -> `50.26548245743669`
- Perimeter: P = 2πR
    - Принимает r - радиус окружности, возвращает ее периметр
        `print(perimeter(4))` -> `25.132741228718345`

## Функции rectangle.py
- Area: S = a * b
    - Принимает a, b - смежные стороны прямоугольника, возвращает его площадь
        `print(area(2, 3))` -> `6`
- Perimeter: P = (a + b) * 2
    - Принимает a, b - смежные стороны прямоугольника, возвращает его периметр
        `print(perimeter(2, 3))` -> `10`

## Функции square.py
- Area: S = a²
    - Принимает a - сторону квадрата, возвращает его площадь
        `print(area(2))` -> `4`
- Perimeter: P = 4 * a
    - Принимает a - сторону квадрата, возвращает его периметр
        `print(perimeter(2))` -> `8`

## Функции triangle.py
- Area: S = a * h / 2
    - Принимает длину основания и высоты треугольника (a, h), возвращает его площадь
        `print(area(2, 3))` -> `3`
- Perimeter: P = a + b + c
    - Принимает длины сторон треугольника (a, b, c), возвращает его периметр
        `print(perimeter(2, 3, 4))` -> `9`
